# مشروع تفريغ دروس تفسير الطبري

هذا المستودع يحتوي على تفريغ دروس "تفسير الطبري" لفضيلة الشيخ حسين بن عبدالرازق المصري، منسقة ومخرجة باستخدام محرك **XeLaTeX** لتكون في قالب كتاب تراثي احترافي جاهز للطباعة والنشر.

## هيكل المشروع
- `main.tex`: الملف الرئيسي الذي يحتوي على الإعدادات، الفهرس، الغلاف، ويستدعي باقي الدروس.
- `src/`: مجلد يحتوي على ملفات الدروس المستقلة (مثل `001.tex`).
- `INSTRUCTIONS.md`: ملف يحتوي على السياق، قواعد التنسيق، والأوسمة المعتمدة للمساعد الذكي.

## طريقة التشغيل (Compilation)
نظراً لاستخدام خطوط عربية وحزمة `polyglossia`، يجب استخدام محرك `XeLaTeX` لتوليد ملف الـ PDF.

افتح الطرفية (Terminal) في مسار المشروع ونفذ الأمر التالي:

```bash
xelatex main.tex
```

*(ملاحظة: لتحديث الفهرس `Table of Contents` وأرقام الصفحات بدقة، يرجى تنفيذ الأمر السابق مرتين متتاليتين).*

## المساهمة والتنسيق
إذا كنت تود إضافة درس جديد، يرجى قراءة ملف `INSTRUCTIONS.md` أولاً لمعرفة الأوسمة المطلوبة (مثل `\begin{ayah}` للآيات، `\rawi{}` للرواة، وغيرها).
